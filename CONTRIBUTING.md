# Contributing to BROW-S3-R

Thank you for your interest in contributing to BROW-S3-R! We welcome contributions from the community to help make this S3 explorer even better.

## How to Contribute

1.  **Fork the Repository**: Create a fork of the repository on your GitHub account.
2.  **Clone the Repository**: Clone your fork to your local machine.
    ```bash
    git clone https://github.com/YOUR_USERNAME/brows3r.git
    cd brows3r
    ```
3.  **Install Dependencies**: Use [Bun](https://bun.sh/) to install dependencies.
    ```bash
    bun install
    ```
4.  **Create a Branch**: Create a new branch for your feature or bug fix.
    ```bash
    git checkout -b chore/your-contribution
    ```
5.  **Make Changes**: Implement your changes, following the existing code style.
6.  **Run Tests**: Ensure that everything is working as expected.
    ```bash
    bun test
    ```
7.  **Commit Changes**: Commit your changes with a descriptive message.
    ```bash
    git commit -m "feat: your new feature"
    ```
8.  **Push and Submit a Pull Request**: Push your branch to your fork and submit a pull request to the main repository.

## Local Development

- `bun dev`: Starts the development server.
- `bun build`: Builds the application for production.
- `bun lint`: Runs the linter.
- `bun check`: Runs prettier and eslint fix.

## Code Style

- We use **Prettier** for code formatting.
- We use **ESLint** for static analysis.
- Follow the existing project structure and modularity.
